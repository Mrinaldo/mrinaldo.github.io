# Mrinal Dharmik — Portfolio Website ⚡✒️

> **"Logic builds the machine. Ink breathes the life into it."**

Personal portfolio website for **Mrinal Dharmik** — Software engineer by day, artisan & storyteller otherwise. Hosted live on GitHub Pages at [mrinaldo.github.io](https://mrinaldo.github.io).

---

## 🌟 The Dual Frequency Experience

The site introduces a reactive dual-state system toggled via the navbar or keyboard shortcuts (<kbd>E</kbd> for Engineer, <kbd>A</kbd> for Artisan):

### ⚡ Engineer Mode (Logic & Architecture)
- **Aesthetic:** Dark obsidian terminal (`#0b0f19`) with blueprint grid lines, neon cyan accents, and monospaced typography (`JetBrains Mono`, `Inter`).
- **Showcase:** Deep-dive architectural breakdowns of featured systems:
  - **Mriter**: Desktop novel writing & publishing studio (Electron, React 19, TipTap, William Shunn format export, EPUB 3 generator).
  - **Mrews**: Knowledge-first curated news feed with dynamic multi-factor affinity scoring (Next.js 15, Supabase, PostgreSQL).
  - **Mreader**: Minimalist distraction-free e-reader engine (React 19, Foliate-js, Dexie IndexedDB).
  - **Web Works Archive**: Portfolio aggregation hub preserving standalone production web platforms (SARC IIT Bombay, SARC Blog, Auronova Consulting, Alumination '17) ([mrinaldo.gitlab.io](https://mrinaldo.gitlab.io/)).
  - **EventsJournal**: Social event community platform with Supabase RLS.

### ✒️ Artisan Mode (Craft & Scribe)
- **Aesthetic:** Warm deckle-edge paper textures (`#faf7f2`), India ink strokes, and editorial serif typography (`Newsreader`, `Caveat`).
- **Interactive Features:**
  - **The Inkwell Scratchpad:** Real-time HTML5 vector ink canvas with adjustable Sakura Micron nib weights (0.1mm - 0.8mm) and exportable sketches.
  - **The Literary Studio:** Study of the complete works of **Fyodor Dostoevsky** and **Jane Austen**, paired with reflections on the **Haruki Murakami** principle (how short stories serve as the natural seedbeds of novellas and novels).
  - **The Fretboard:** Interactive standard-tuning guitar string synthesizer powered by the Web Audio API, paired with Spotify integration.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React + Bespoke Brand SVGs
- **Build Tool:** Vite 6
- **Deployment:** GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)

---

## 💻 Local Development

```bash
# Clone the repository
git clone git@github.com:Mrinaldo/mrinaldo.github.io.git
cd mrinaldo.github.io

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the site locally.

---

## 🚀 Building & Deployment

The repository is configured with GitHub Actions to automatically build and deploy the production bundle to GitHub Pages upon pushing to `master`.

To trigger a manual local build:
```bash
npm run build
```
Production assets are generated in `dist/`.
